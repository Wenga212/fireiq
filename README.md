# FireIQ — Multi-Vendor Firewall Intelligence

Live URL (after deploying): **https://YOUR-USERNAME.github.io/fireiq/**

A single-page firewall comparison platform covering Fortinet, Check Point, Palo Alto, and Cisco. Specs are extracted from official vendor datasheets you commit to this repo.

## How it works (the short version)

```
You drop a vendor datasheet PDF here:    →    GitHub Action parses it:    →    Live site updates:
       datasheets/fortinet.pdf                   scripts/build.py                  index.html shows the new data
```

When a vendor publishes a new datasheet:
1. Download the file from the vendor's website
2. Drop it in `datasheets/` (replacing the existing one)
3. Commit + push
4. GitHub Actions parses it, rebuilds `data/firewalls.json`, the site updates within ~2 minutes

No live web scraping, no CORS issues, no parser maintenance for vendors who don't change their PDF format.

## Folder structure

```
fireiq/
├── index.html                     The web app (single-file HTML)
├── datasheets/                    Source-of-truth vendor docs
│   ├── README.md                  ← read this when refreshing data
│   ├── fortinet.pdf
│   ├── checkpoint.pdf
│   ├── paloalto.pdf
│   ├── cisco-1200.html
│   └── manual-overrides.json
├── data/
│   ├── firewalls.json             ← auto-generated by build.py
│   └── sources-status.json        ← per-source extraction stats
├── scripts/
│   ├── build.py                   Main parser (vendor parsers inside)
│   ├── inspect.py                 Helper: print PDF/HTML structure
│   └── requirements.txt           Python deps
└── .github/workflows/
    └── rebuild.yml                Triggers build.py on commits to datasheets/
```
